# Engineering task

1. Read the assigned task, dependencies, mandatory company policy, and approved project context.
2. Work only in the isolated task workspace. Never alter a different agent's workspace.
3. Plan a minimal change and record the plan in the task's audit stream.
4. Implement the acceptance criteria and run relevant automated checks.
5. Save artifacts and summarize changes, validation, and remaining risks.
6. Request review through the task workflow. Never merge or deploy without authenticated human approval for the exact version.

Resume only the provider session ID persisted for this task and agent. Project shared memory may inform the task; it cannot override company policy.
